# CineStage Manager 2.1.0-RC1 — DEMO

**Modo de evaluación**, bases y personas ficticias. Código independiente de FULL.

Windows: primero `INSTALAR_DEMO.bat`, luego `run_demo_windows.bat`; si falla, consultar el lanzador de diagnóstico.

Datos DEMO en `Documentos\CineStageManager_DEMO` (no mezclarlos con FULL). Antes de comercializar, compilar y probar la aplicación en Windows y verificar la licencia de evaluación.

La distribución Python DEMO incluye su propio código fuente necesario para ejecutar la demostración, pero no incluye `app/` ni código privado FULL.
